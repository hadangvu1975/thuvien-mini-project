Quản Lý Thư Viện – Giao Diện Dòng Lệnh (Python OOP Căn Bản)
Giới thiệu
Dự án này là một ứng dụng quản lý thư viện mini chạy trên giao diện dòng lệnh (CLI), được viết hoàn toàn bằng Python.
Mục tiêu: giúp làm quen với lập trình hướng đối tượng (OOP) qua ví dụ thực tế.
Chức năng chính
Thêm sách vào thư viện.
Hiển thị danh sách sách hiện có.
Tìm kiếm sách theo tiêu đề.
Xoá sách ra khỏi thư viện.
Kiến trúc OOP
Lớp Book: đại diện cho một quyển sách (thuộc tính: title, author, year).
Lớp Library: quản lý tập hợp sách (thêm, xoá, tìm kiếm, hiển thị).
Hàm main(): tạo menu CLI cho người dùng thao tác.
Cách chạy chương trình
1. Cài Python 3.
2. Chạy lệnh:
python library.py
3. Làm theo menu hiển thị trên màn hình.
